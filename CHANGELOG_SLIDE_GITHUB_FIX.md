# Student AI — slayd tili va GitHub ro'yxati tuzatishlari

## Slaydlar
- AI uchun qat'iy til talabi kuchaytirildi: barcha ko'rinadigan matnlar o'zbek tilida, lotin yozuvida bo'lishi so'raladi.
- Inglizcha standart titul yozuvi `Professional presentation` o'rniga `Professional taqdimot` qilindi.

## GitHub Developer
- Papka tarkibini olish limiti 200 tadan 1000 tagacha oshirildi (GitHub Contents API chegarasi doirasida).
- Fayl va papkalar 35 tadan inline tugmali bo'limlarga ajratiladi.
- Birinchi bo'lim developer menyu xabarida, sig'magan qolgan bo'limlar esa alohida keyingi Telegram xabarlarida yuboriladi.
- Tugmalarning callback indekslari umumiy ro'yxatdagi asl indeksni saqlaydi; fayl/papka tanlash amallari avvalgidek ishlaydi.
- Yangi papka ochilganda avvalgi ro'yxatning qo'shimcha xabarlari tozalanadi.

## Tekshiruv
- Python compileall: muvaffaqiyatli.
- GitHub ZIP/delete va PPTX professional testlari: 16 passed, 1 skipped.
- Telegram API bilan haqiqiy deploy/suhbat testi ushbu lokal muhitda bajarilmadi.
